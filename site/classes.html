Common questions

Is this live, or self-paced?
Self-paced. Every class is on demand, so your kid can start tonight and watch when it suits your family. Help comes from Get Unstuck, where Coach answers in minutes and a real person reads every thread.
What ages is this for?
Built for 11 to 17. Middle schoolers do best with a parent watching the first classes alongside; high schoolers usually run with it on their own.
Does my kid need to know how to code?
No. Every project uses tools that build from a description of what you want. Kids who like code can go deeper, but nothing requires it.
What do they need?
A laptop or Chromebook and an internet connection. Most tools have a free tier. Where a class uses a paid tool, the class says so before anyone signs up for anything.
Is it safe?
Members can't message each other; everything is in spaces the team can see. A parent or guardian email and consent are required before a student can join, and the rules and Coach both refuse full names, schools, addresses and social handles.
